# Exploratory_Data_Analysis_Project
Creating scripts for comprehensive data analysis 

A data analytics project that contains scripts for different types of exploratory data analyses like:

- Database exploration
- Dimensions exploration
- Date exploration
- Measures exploration
- Magnitude analysis
- Ranking analysis

IMPORTANT PREREQUISITE: This Project depends on the Data_Warehouse_Project. 
Before running this analysis, you need to set up and run the data warehouse : https://github.com/0F1l1p0/Data_Warehouse_Project

Run the SQL scripts in your preferred SQL environment (e.g., SQL Server Management Studio) after the data warehouse has been set up.
The project focuses on EDA(Exploratory Data Analysis) such as calculating the key metrics of the business and making comparisons between values regarding the category it belongs to.
